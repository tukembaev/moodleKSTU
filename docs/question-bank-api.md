# Коллекция вопросов — API для бэкенда

Сейчас коллекция вопросов живёт только на клиенте (`localStorage`). Ниже — что фронту нужно от бэкенда.

Сервис: **edu**, base URL как у тестов: `/api/v1/edu/`.  
Авторизация: cookie / JWT текущего пользователя. Коллекции — **личные** (преподаватель видит только свои).

---

## Сущности

**Коллекция (`QuestionBank`)** — набор вопросов. Не привязана к курсу.

**Вопрос (`BankQuestion`)** — тот же формат, что в редакторе теста: текст, опции, картинки, один или несколько правильных ответов.

Правильный ответ сравнивается **по тексту варианта** (`option.text`), не по `id`.

---

## Эндпоинты

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/question-banks/` | Список коллекций |
| `POST` | `/question-banks/` | Создать коллекцию |
| `GET` | `/question-banks/{bank_id}/` | Одна коллекция + вопросы |
| `DELETE` | `/question-banks/{bank_id}/` | Удалить коллекцию и все её вопросы |
| `POST` | `/question-banks/{bank_id}/questions/` | Добавить вопрос |
| `PUT` | `/question-banks/{bank_id}/questions/{question_id}/` | Обновить вопрос |
| `DELETE` | `/question-banks/{bank_id}/questions/{question_id}/` | Удалить вопрос |

Обновление названия/описания коллекции фронту **не нужно**.

---

## Структуры

### Коллекция (ответ)

```json
{
  "id": "uuid",
  "name": "Программирование",
  "description": "Вопросы по основам языка",
  "createdAt": "2026-09-10T12:00:00.000Z",
  "questions": []
}
```

`createdAt` — ISO 8601. `description` может быть `""`.

### Вопрос (ответ)

```json
{
  "id": "uuid",
  "question": "Что такое HTTP?",
  "questionImagePreview": "https://.../q.png",
  "options": [
    { "id": "uuid", "text": "Протокол", "imagePreview": null },
    { "id": "uuid", "text": "Язык", "imagePreview": "https://.../opt.png" }
  ],
  "correctAnswer": "Протокол",
  "multipleAnswers": false
}
```

- `multipleAnswers: false` → `correctAnswer` — **строка** (текст правильного варианта).
- `multipleAnswers: true` → `correctAnswer` — **массив строк**.
- Картинки в ответах — **публичный URL** (или `null` / поле отсутствует). Не data URL.
- Минимум **2 варианта**. У каждого варианта обязателен непустой `text`.

---

## Вход / выход по методам

### `GET /question-banks/`

**Вход:** нет.

**Выход:** `QuestionBank[]`.

Для списка карточек достаточно `id`, `name`, `description`, `createdAt` и числа вопросов.  
Диалог «вставить в тест» берёт вопросы из выбранной коллекции.

Допустимо:

- в списке отдавать `questions: []` и `questionsCount: number`, полный массив — только в `GET .../{id}/`;
- или сразу вкладывать `questions` в каждый элемент.

Если в списке нет вопросов, фронт дополнительно вызовет `GET /question-banks/{id}/` при выборе коллекции.

### `POST /question-banks/`

**Вход:**

```json
{ "name": "Программирование", "description": "опционально" }
```

`name` обязателен, минимум 2 символа.

**Выход:** созданная коллекция, `questions: []`. Нужен `id` — фронт сразу открывает деталку.

### `GET /question-banks/{bank_id}/`

**Выход:** коллекция с полным массивом `questions`.  
`404`, если нет или чужая.

### `DELETE /question-banks/{bank_id}/`

**Выход:** `204` или `{ "ok": true }`. Каскадно удалить вопросы.

---

### Вопросы: JSON или `multipart/form-data`

В редакторе картинки — файлы (`File`). Удобнее **multipart** (как у `testing/`).

Поля формы:

| Поле | Тип | Описание |
|---|---|---|
| `question` | string | Текст вопроса |
| `multipleAnswers` | `"true"` / `"false"` | Несколько правильных |
| `correctAnswer` | string или JSON-массив | Текст(ы) правильных вариантов |
| `questionImage` | file, optional | Картинка к вопросу |
| `options` | JSON-строка | `[{ "id"?: uuid, "text": "..." }, ...]` |
| `optionImage_0`, `optionImage_1`, … | file, optional | Картинка варианта по индексу |

Если картинку не меняют — файл не слать, оставить старый URL.

Альтернатива: JSON + URL картинок (файлы грузятся отдельным upload). Главное — в ответах всегда URL в `questionImagePreview` / `options[].imagePreview`.

**Выход `POST`/`PUT` вопроса:** объект `BankQuestion`.

---

## Валидация (как на фронте)

- Текст вопроса не пустой.
- Все варианты с непустым `text`.
- Один ответ: `correctAnswer` — непустая строка, совпадает с `text` одного варианта.
- Несколько ответов: массив, длина ≥ 1, каждый элемент — `text` существующего варианта.
- Удаление коллекции удаляет все вопросы.

---

## Как это используется на фронте

1. Страница `/question-bank` — список, создать, удалить.
2. `/question-bank/bank/:id` — просмотр, CRUD вопросов.
3. Создание теста — диалог выбора вопросов из коллекции: копирование в черновик теста, **без связи** вопрос в тесте ↔ вопрос в коллекции.

Отдельный API «импорт в тест» не нужен.
