# Успеваемость на карточке курса — API для бэкенда

Фронт показывает статистику на карточке в списке «Мои курсы». Объект один и тот же для студента и преподавателя: лишние поля можно не присылать, фронт их не рисует.

Сервис: **users** (тот же, что список курсов).  
Авторизация: cookie / JWT текущего пользователя.

---

## Куда добавить

| Метод | URL | Кто видит |
|---|---|---|
| `GET` | `my-courses/` | Активные курсы. Студент и преподаватель. |
| `GET` | `my-courses/archive/` | Архив. Только преподаватель. |

В каждый объект курса в ответе добавить вложенный объект `academic_performance`.

Числа — целые, кроме `average_score` (число с дробной частью). Если данных нет, поле можно опустить или прислать `0`. `null` не присылать.

---

## Студент

Карточка: три блока и progress bar. Полоска = `student_points / points_total` (0–100%). Если `points_total` = 0, полоска пустая.

| Ключ | Тип | Что означает |
|---|---|---|
| `works_submitted` | `number` | Сколько работ студент уже сдал |
| `works_total` | `number` | Сколько работ нужно сдать всего |
| `tests_submitted` | `number` | Сколько тестов студент сдал |
| `tests_remaining` | `number` | Сколько тестов ещё осталось сдать |
| `student_points` | `number` | Баллы студента по курсу. Если поля нет, фронт берёт `course_points` |
| `points_total` | `number` | Максимум баллов курса. Если поля нет, фронт берёт `max_points` |

`works_*` — задания курса (лабораторные, практики и прочие сдачи), без тестов. Тесты считаются только в `tests_*`.

Пример:

```json
{
  "id": "…",
  "discipline_name": "Математика 4",
  "academic_performance": {
    "works_submitted": 3,
    "works_total": 10,
    "tests_submitted": 2,
    "tests_remaining": 1,
    "student_points": 42,
    "points_total": 100
  }
}
```

На карточке это читается как `3/10` работы, `2/1` тесты (сдано / осталось), `42/100` баллы.

## Преподаватель

Карточка: три блока, без progress bar.

| Ключ | Тип | Что означает |
|---|---|---|
| `students_count` | `number` | Сколько студентов на курсе. Если поля нет, фронт берёт `count_stud` |
| `works_checked` | `number` | Сколько работ преподаватель уже проверил |
| `average_score` | `number` | Средний балл всех студентов курса |

`works_checked` — число проверенных сдач по курсу, не число студентов. Непроверенные в это поле не входят.

Пример:

```json
{
  "id": "…",
  "discipline_name": "Математика 4",
  "academic_performance": {
    "students_count": 28,
    "works_checked": 64,
    "average_score": 76.5
  }
}
```

На карточке: `28` студенты, `64` проверено, `76.5` средний балл.
