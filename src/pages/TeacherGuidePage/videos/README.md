# Видео для страницы «Руководство»

Положите файл в папку раздела. Страница подхватит его сама: перезапуск сервера не нужен, достаточно сохранения файла.

Имя файла — как в списке, расширение `mp4`, `webm`, `mov` или `m4v`.

## Курсы — `01-courses/`

- `01-create-course.mp4` — Часть 1. Создание курса
- `02-course-page.mp4` — Часть 2. Страница курса
- `03-add-theme.mp4` — Часть 3. Добавление темы
- `04-materials.mp4` — Часть 4. Учебные материалы

## Тестирование — `02-testing/`

- `01-create-test.mp4` — Часть 1. Создание теста
- `02-question-bank.mp4` — Часть 2. Коллекция вопросов

## Начало работы — `03-start/`

- `01-login.mp4` — Часть 1. Вход в систему

Файл с другим именем в этих папках тоже появится в списке. Новая папка рядом с этими станет новым разделом.
